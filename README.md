Game Name: Mountain Peaks
A game where you farm peaches and try to pay rent before the timer ends or else you lose!
Try to make as much rounds as possible!

- guide is in game
  WASD to move character
  E to interact,
  click icons and equip tools to interact
  esc to pause game
  L to save game
  backspace to reset game

Guide to Download
- Go to release file >> https://github.com/Zaaoooow/Week5MountainPeaks/releases/tag/v1.0.0
- download Week5MountainPeaks
- extract it
- click on the exe file and run it
- HAVE FUN!
